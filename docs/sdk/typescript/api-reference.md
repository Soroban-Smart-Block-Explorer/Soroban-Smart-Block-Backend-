# TypeScript SDK — API Reference

| Export                                                                                                                                                        | Kind           | Description                                                                                                                                                                                                         |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `SorobanClient(options)`                                                                                                                                      | class          | Entry point; see README options table                                                                                                                                                                               |
| `client.call(id, params?)`                                                                                                                                    | method         | Any of the operations in [`parity-matrix.md`](../parity-matrix.md); `params: { path?, query?, body?, signal?, headers? }` typed per operation (`OperationParams[id]`); resolves to `OperationTypes[id]['response']` |
| `client.paginate(id, params?, { maxPages? })`                                                                                                                 | async iterator | Yields items across cursor (`nextCursor`) or page (`page`) pagination                                                                                                                                               |
| `client.transactions.list/get`, `events.list/get`, `contracts.list/get`, `tokens.list/get`, `wallets.transactions/events`, `network.status`, `search.suggest` | methods        | Curated wrappers over `call`                                                                                                                                                                                        |
| `client.realtime.graphql(query, variables?, signal?)`                                                                                                         | async iterator | GraphQL subscription over SSE; throws `SorobanError("<CODE>: message")` on GraphQL errors                                                                                                                           |
| `client.realtime.feed()`                                                                                                                                      | `SorobanFeed`  | Feed subscriptions, backfill, WebSocket and SSE (1.0 API)                                                                                                                                                           |
| `OPERATIONS`, `OPERATION_COUNT`, `SPEC_VERSION`, `SPEC_FINGERPRINT`                                                                                           | consts         | Generated operation metadata                                                                                                                                                                                        |
| `OperationId`, `OperationTypes`, `OperationParams`, `Models.*`                                                                                                | types          | Generated types                                                                                                                                                                                                     |
| `SorobanError` and subclasses                                                                                                                                 | classes        | See README error table; API errors carry `status`, `code`, `requestId`, `body`, `rateLimit` (`limit`, `remaining`, `reset`, `tier`) and `RateLimitError.retryAfterMs`                                               |
| `RequestEvent`                                                                                                                                                | type           | `onRequest` payload: `operationId, method, path, attempt, status, durationMs, outcome, willRetry, requestId, rateLimit`                                                                                             |

Error body shapes returned by the API (`{ error, code?, … }`) are preserved in
`err.body`. Rate-limit headers (`X-RateLimit-Limit/Remaining/Reset/Tier`,
`Retry-After`) are parsed into `err.rateLimit` / `retryAfterMs` and emitted on
every `RequestEvent`.
