# Python Client — API Reference

| Symbol                                                                                                                                                                                       | Description                                                                                                                                                                                                                                                                                                                                                                                    |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Client(api_key=None, base_url=DEFAULT_BASE_URL, timeout=10.0, max_retries=2, max_retry_delay=30.0, on_request=None, opener=None)`                                                           | Client                                                                                                                                                                                                                                                                                                                                                                                         |
| `client.call(operation_id, path=None, query=None, body=None, headers=None)`                                                                                                                  | Any operation; returns parsed JSON (`dict`/`list`/scalar) or text                                                                                                                                                                                                                                                                                                                              |
| `client.paginate(operation_id, path=None, query=None, max_pages=1000)`                                                                                                                       | Iterator over items (cursor or page pagination)                                                                                                                                                                                                                                                                                                                                                |
| `client.transactions.list(**q)/get(hash)`, `events.list/get(id)`, `contracts.list/get(address)`, `tokens.list/get(address)`, `wallets.transactions/events(address, **q)`, `network.status()` | Curated wrappers                                                                                                                                                                                                                                                                                                                                                                               |
| `client.stream_feed(channels, timeout=None)`                                                                                                                                                 | Iterator of `(event, data)` from `/feed/sse`                                                                                                                                                                                                                                                                                                                                                   |
| `OPERATIONS`, `OPERATION_COUNT`, `SPEC_VERSION`, `SPEC_FINGERPRINT`                                                                                                                          | Generated metadata                                                                                                                                                                                                                                                                                                                                                                             |
| `models.*`                                                                                                                                                                                   | Generated `TypedDict`s                                                                                                                                                                                                                                                                                                                                                                         |
| `RequestEvent`                                                                                                                                                                               | `operation_id, method, path, attempt, status, duration_ms, outcome, will_retry, request_id, rate_limit`                                                                                                                                                                                                                                                                                        |
| Errors                                                                                                                                                                                       | `SorobanError` → `RequestValidationError`, `NetworkError`, `TimeoutError`, `ApiError` → `BadRequestError` 400, `AuthenticationError` 401, `PermissionDeniedError` 403, `NotFoundError` 404, `ConflictError` 409, `UnprocessableError` 422, `RateLimitError` 429 (`retry_after`), `ServerError` 5xx. `ApiError` has `status, code, request_id, body, rate_limit(limit, remaining, reset, tier)` |
