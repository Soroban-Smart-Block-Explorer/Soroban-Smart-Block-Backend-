# Exports

List and download data exports.

## Steps

1. Start the backend (`docker compose up`) and note the base URL.
2. Run the example: `BASE_URL=http://localhost:3000 node docs/tutorials/examples/04-exports.mjs`.
3. Read the script; it calls `/api/v1/exports` and prints the JSON response.
4. Adapt the request parameters to your own contracts.
