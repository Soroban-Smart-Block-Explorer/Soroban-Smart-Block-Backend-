# Alerts

Inspect alerts and alert rules for a contract or account.

## Steps

1. Start the backend (`docker compose up`) and note the base URL.
2. Run the example: `BASE_URL=http://localhost:3000 node docs/tutorials/examples/05-alerts.mjs`.
3. Read the script; it calls `/api/v1/alerts` and prints the JSON response.
4. Adapt the request parameters to your own contracts.
